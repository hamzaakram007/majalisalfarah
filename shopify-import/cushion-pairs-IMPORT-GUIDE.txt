How to import in Shopify
------------------------
1. Shopify Admin → Products → Import
2. Upload cushion-pairs-shopify-products.csv
3. Confirm 6 products with 3 combo variants each
4. Click Import products

How to add the combo images
---------------------------
After import, for each product:
  1. Open the product in Shopify Admin
  2. Upload the 3 matching images from images/cushion-pairs/
  3. Assign each image to its Combo variant
     (Product → Variants → click variant → choose media)

Example for Pair 1 (Soft Linen):
  Sand + Ivory              -> pair1-linen-sand-ivory.jpg
  Olive + Mocha             -> pair1-linen-olive-mocha.jpg
  Soft Gray + Warm White    -> pair1-linen-gray-white.jpg

Currency: set store to SAR
