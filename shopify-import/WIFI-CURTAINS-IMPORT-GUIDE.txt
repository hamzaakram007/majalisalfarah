Category: Curtains

How to import in Shopify
------------------------
1. Shopify Admin → Products → Import
2. Upload wifi-curtains-shopify-products.csv
3. Confirm 1 product with 6 color variants
4. Click Import products

How to add the color images
---------------------------
After import, open the product in Shopify Admin:
  1. Upload all 6 images from images/wifi-curtains/
  2. Assign each image to its color variant
     (Product → Variants → click variant → choose media)

  Cream Ivory  -> wifi-curtain-cream-ivory.jpg
  Soft Sand    -> wifi-curtain-soft-sand.jpg
  Pearl White  -> wifi-curtain-pearl-white.jpg
  Mist Gray    -> wifi-curtain-mist-gray.jpg
  Soft Sage    -> wifi-curtain-soft-sage.jpg
  Blush Pink   -> wifi-curtain-blush-pink.jpg

Currency: set store to SAR
