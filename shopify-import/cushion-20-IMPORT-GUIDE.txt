Pack sizes & pricing
--------------------
Each product has 4 variants (Option: Pack Size):
  1 Piece  = base price × 1.0
  2 Piece  = base price × 1.9
  3 Piece  = base price × 2.7
  4 Piece  = base price × 3.4

Example (Desert Linen, base 79 SAR):
  1 Piece = 79 SAR
  2 Piece = 150.10 SAR
  3 Piece = 213.30 SAR
  4 Piece = 268.60 SAR

How to import in Shopify
------------------------
1. Shopify Admin → Products → Import
2. Upload cushion-20-shopify-products.csv
3. Confirm 20 products with 4 Pack Size variants each (80 variants)
4. Click Import products

How to add the 5 photos per product
-----------------------------------
After import, for each product:
  1. Open the product in Shopify Admin
  2. Upload the 5 matching images from images/cushion-20/
     Example for p01:
       p01-photo1-hero.jpg
       p01-photo2-lifestyle.jpg
       p01-photo3-detail.jpg
       p01-detail-en.jpg
       p01-detail-ar.jpg
  3. Set image order: Hero → Lifestyle → Detail → EN card → AR card
  4. Optionally assign the hero image to each Pack Size variant

Currency: set store to SAR
