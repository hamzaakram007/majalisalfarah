Shopify Import Guide – L-Shaped Sofas (6 Meter) + Color Images
==============================================================

Main CSV (Shopify import):
  l-shape-sofas-shopify-products.csv

Color images (18 total):
  images/color-variants/
    style1-*.jpg  = Majlis Floor sofa (6 colors)
    style2-*.jpg  = Contemporary Modular sofa (6 colors)
    style3-*.jpg  = Curved-Arm Luxury sofa (6 colors)

View images on phone/computer:
  Open: color-variants-gallery.html
  Or open folder: images/color-variants/

Image map (SKU -> file):
  color-variant-image-map.csv

Colors for each style
---------------------
1. Taupe Greige
2. Charcoal Gray
3. Midnight Navy
4. Forest Green
5. Cream Ivory
6. Terracotta Rust

How to import in Shopify
------------------------
1. Shopify Admin → Products → Import
2. Upload l-shape-sofas-shopify-products.csv
3. Confirm 3 products with 6 color variants each
4. Click Import products

How to add the color images
---------------------------
After import, for each product:
  1. Open the product in Shopify Admin
  2. Upload all 6 matching color images from images/color-variants/
  3. Assign each image to its color variant
     (Product → Variants → click variant → choose media)

Example for Style 1 (Majlis Floor):
  Taupe Greige     -> style1-taupe-greige.jpg
  Charcoal Gray    -> style1-charcoal-gray.jpg
  Midnight Navy    -> style1-midnight-navy.jpg
  Forest Green     -> style1-forest-green.jpg
  Cream Ivory      -> style1-cream-ivory.jpg
  Terracotta Rust  -> style1-terracotta-rust.jpg

Same pattern for style2-* and style3-*.
