How to import in Shopify
------------------------
1. Open Shopify Admin → Products → Import
2. Upload: l-shape-sofas-shopify-products.csv
3. Confirm preview looks correct (3 products, 6 variants each)
4. Click Import products

Add images (important)
----------------------
Image URLs were left blank because Shopify needs public HTTPS links.

Option A (recommended):
  1. Import the CSV first
  2. Open each product
  3. Upload the matching image from the /images folder
  4. Optionally duplicate/edit the image per color variant later

Option B:
  1. Upload images to Shopify Admin → Content → Files
  2. Copy each image URL
  3. Paste into the Image Src column of the CSV
  4. Re-import with "Overwrite products with matching handles"

Currency
--------
Set your store currency to SAR (Saudi Riyal) in:
  Settings → Store details / Markets / Payments
