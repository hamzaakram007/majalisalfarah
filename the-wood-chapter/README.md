# The Wood Chapter — Comfort Forward 2026

Sculptural seating and sofa product photography for Comfort Forward 2026.

## Browse

- [index.html](index.html) — collection landing
- [all-angles.html](all-angles.html) — sculptural seating front / angle / side
- [sofas-gallery.html](sofas-gallery.html) — **all sofas** (Modern + Place + Lifestyle)
- [modern-sofas/index.html](modern-sofas/index.html) — modern sofas 5-image sets
- [place-sofas/index.html](place-sofas/index.html) — place / commercial sofas 5-image sets
- [lifestyle-sofas/index.html](lifestyle-sofas/index.html) — real-home lifestyle sofas 5-image sets

Open locally:

```bash
cd the-wood-chapter
python3 -m http.server 8765
```

Then visit http://localhost:8765
