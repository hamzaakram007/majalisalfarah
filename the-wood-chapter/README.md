# The Wood Chapter — Comfort Forward 2026

Sculptural Seating Edition product photography: **20 pieces × 3 angles = 60 images**, plus detail pages.

## Browse

- [index.html](index.html) — collection landing
- [all-angles.html](all-angles.html) — every piece with front / angle / side
- [products/](products/) — individual product pages with specs

Open locally:

```bash
cd the-wood-chapter
python3 -m http.server 8765
```

Then visit http://localhost:8765

## Angles per piece

| Angle | File suffix | Description |
|-------|-------------|-------------|
| Front | `*-front.jpg` | Straight-on product view |
| Angle | `*-angle.jpg` | Three-quarter / 45° depth view |
| Side | `*-side.jpg` | Side profile |

Images live in `products/images/`. Catalog crop references are in `products/references/`.

## Product data

- `products/products.json` — names, materials, dimensions, prices, image paths
- `shopify-sculptural-seating.csv` — Shopify product import (attach images after import)
