## How to brief the agency (future requests)

1. **Reel** → full production package from the template  
2. **Product photos** → preserve exact design, colour, texture, proportions  
3. **Showroom footage** → commercial edit around real assets  
4. **Viral ideas** → concepts tied to psychology + brand relevance  
5. **Ads** → strategy, creatives, targeting, conversion path  
6. **Analytics** → diagnose creatives and give measurable next tests  
7. **AI prompts** → production-ready, copy-paste prompts  

## North-star outcome

Attention → qualified WhatsApp enquiries → showroom visits / orders → repeat buyers and referrals.  
Viral views without commercial outcomes are not success.
