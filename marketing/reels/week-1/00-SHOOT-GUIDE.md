## One-day production plan (recommended)

### Block A — Showroom (morning light)

1. Wide majlis / sofa hero plates (Day 1, 4)  
2. Two “this or that” sofa angles — mark floor tape for identical framing  
3. Curtain sample wall / hanging samples (Day 3)  
4. Stories: entrance, signage, WhatsApp sticker footage  

### Block B — Workshop (midday)

1. Sewing, fabric pull, foam touch (Day 1 + Day 2 inserts)  
2. Before/after sofa if project is on site; else photograph reference stills for edit  

### Block C — Customer install (if permissioned)

1. Before/after locked camera mark (Day 2)  
2. Curtain room plate if available (Day 3 B-roll)  

**If only phone + showroom:** Shoot Days 1, 3, 4 fully; for Day 2 use approved stills + Ken Burns + workshop inserts — never AI-morph the real sofa.
