Download All Photos (ZIP) Open Photos Folder Open Gallery

iPhone

  1. Tap Download All Photos (ZIP)
  2. Open the ZIP in Files
  3. Select images → Share → Save Image / Save to Photos
  4. Or open Gallery and long-press each photo → Add to Photos

Android

  1. Tap Download All Photos (ZIP)
  2. Open the ZIP with Files / Gallery
  3. Extract, then select images → Share → Save to Gallery / Photos
  4. Or open Gallery and long-press each photo → Download
