Majalis Alfarah - Website Files
==============================

Folder structure for launching bilingual Saudi furniture store website with foam, sofas, and home décor:

Key Folders:
- css/ → Global styles
- catalog/ → Product pages and catalog.json
- ar/ → Arabic homepage
- payments/ → Local payment method pages (Mada, STCPay, Apple Pay)
- blog/ → News & blog posts
- images/ → All visual assets
- social/ → Prewritten social captions
- admin/ → Admin portal
- optional/, guide/, restore/ → Optional modules and support files

Use cPanel > File Manager or FTP to upload and extract this in /public_html or subfolder.

More details in guide/Launch_Guide_EN.txt
