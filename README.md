# Majalis Alfarah

The **full ecommerce ecosystem** lives in the [`web/`](web/) folder (Next.js + Supabase + Vercel).

The older static HTML site is preserved in [`majalisalfarah/`](majalisalfarah/) for reference.

**The Wood Chapter — Comfort Forward 2026** sculptural seating product shots (20 pieces × 3 angles) live in [`the-wood-chapter/`](the-wood-chapter/).

## Quick start

```bash
cd web
npm install
cp .env.example .env.local
npm run dev
```

Open http://localhost:3000/en — see [web/README.md](web/README.md) and [web/DEPLOYMENT.md](web/DEPLOYMENT.md).

Daily product posts to social media are managed in admin at `/admin/social` (see Social section in [web/DEPLOYMENT.md](web/DEPLOYMENT.md)).
